LCA 商业安装包（无源码）

1. cp .env.example .env   # 修改 JWT_SECRET 等
2. 单机:   make docker-up
   高可用: make docker-up-ha
3. 浏览器打开 http://服务器IP ，默认 admin / admin123
4. 激活授权码后，在「服务监控」一键部署 Agent

说明:
- 安装包内已含 release/bin 预编译程序与 release/web-dist 前端。
- make 会检查 Docker 与 vm.max_map_count，不会在客户机编译。
- 不要把任何 Go / Vue 源码放进本仓库。
